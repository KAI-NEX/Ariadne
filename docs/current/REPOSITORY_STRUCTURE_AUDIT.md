## Dependency/reference map

```text
app.py
  ├── src/career_evidence.py
  ├── src/extraction/extract_pdf_text.swift
  ├── src/extraction/extract_pdf_visual_text.swift
  ├── src/extraction/ocr_with_vision.swift
  ├── data/schema.sql
  ├── data/job_radar.db
  └── public/

scripts/
  ├── imports app.py for SQLite/local runtime helpers where required
  └── imports src/ provider/model modules where required

tests/
  ├── imports app.py and src/ modules
  ├── invokes src/extraction Swift adapters
  └── loads public/career-evidence-domain.js for domain regression

document_benchmark/run_benchmark.py
  ├── imports src/career_evidence.py
  └── invokes src/extraction Swift adapters
```

Updated references include Python imports, `Path` roots, Swift subprocess paths, schema path, README commands, benchmark commands, Markdown file references and the navigation guide.

The benchmark harness uses the configured bundled Python runtime because its optional benchmark-only libraries (`pdfplumber`, `pypdf`) are not installed in the macOS system Python. This is an existing runtime boundary, not a production dependency or reorganization regression.
