# 本机优先、用户自带连接的发布方向

决定日期：2026-09-17；开发审阅使用 Astra。本文区分已落实的本机改进与后续发布工作，不表示已部署公网。

## 用户确认的取舍

- 优先照顾项目所有者的本机日常体验，首选自己的 Codex，同时保留自己的 DeepSeek。
- 产品后续对外发布。用户使用自己的 API 凭据，或者下载本地包后连接自己的 Codex；不共享开发者账号，不由开发者密钥代付模型费用。
- 网页应有真实可用的业务路径。官网与 Web 工作区保持既定的不同 origin；下载包不是 Apple App，也应有可复现的安装、连接、保存和恢复流程。
- 用户随后明确调整：每次打开入口先选择模型或本地运行，点击继续后进入工作空间；首页不提供「返回工作空间」快捷入口。已有连接配置保留。

## 架构审阅结论

| 视角 | 判断与行动 |
| --- | --- |
| 架构设计 | 保留原生前端与 Python 模块化单体，共用领域校验和能力 authority。分别处理本机凭据、网页请求凭据与 Codex 配对；不把本机服务直接开放到公网。 |
| 软件设计 | 优先修复“连接成功但执行没有使用该 Key”的断点；只读原件按 ID 获取。写事务继续保留完整版本/冲突与文件完整性检查；不以删校验换速度。 |
| 产品 | 打开先选择模型或本地运行，点击继续进入工作空间；明确自己的账号、传输目的和费用。Local 先保存原件；未接通或未适配的服务明确不可执行。 |
| 传播与首次体验 | 对外承诺围绕“保存自己的资料、理解目标职位、自己控制模型与保存”。只展示已验收能力，公开说明下载平台与部署限制，不把模型名或测试图片连通当作完整质量认证。 |

避免现在重写框架、微服务化或增加通用 Agent 平台。`v1-pages.js` 与 `app.py` 的大文件后续可按页面/路由边界渐进拆分；单纯少写几行不等于省内存或省模型额度。

## 本轮已实现的边界

- 根入口与 `/index.html` 均显示运行选择页，不自动跳转工作空间；保留根页面的启动器就绪检测兼容性。localhost 沿用原有 127.0.0.1 规范地址，不迁移既有工作区。
- 有资格的 Codex 在连接列表优先展示。本机直接选择自己的 Codex，无需先配对；浏览器使用远端网页时仍走有时限、限定 origin 的本地连接器。没有自动登录、切换应用模型或调用模型。
- DeepSeek 添加入口使用调用者自己的 Key 进行固定测试图片验证，点击前说明费用及不含个人材料。图像连接验证复用既有多模态/领域资格，不将本次检查称为新的 PDF 质量验证。Gemini/Qwen 历史入口保留但不可选择执行。
- Key 保留于用户当前浏览器，并且只通过本机请求头交付给六条对应的 DeepSeek 领域接口。`browser-key://deepseek/request` 是无秘密的来源标识；缺失/无效 Key 或来源变化明确失败，不回退到 Keychain。旧的本机 Keychain 配置仍可使用；两种来源不混用。Codex 请求、连接器和无关地址不携带此 Key。
- 原件恢复新增独立 `getRecord` / `read_record`，只读取所需记录，再按需读取并校验原件。原来的列表 metadata 路径已经存在，本轮没有把它描述成新增能力。保存事务保持原有快照、hash、幂等与版本边界。

## 后续网页与分发验收

本轮的公开网页 API 执行层**尚未实现或部署**。页面明确说明这一点；目前用户可在下载版使用自己的 API，或通过已有连接器使用自己的 Codex。不可宣称“静态文件上传后，网页 API 全部可用”。

公开网页自带 API 的下一阶段应复用现有 Python 领域执行层，提供单独的、无开发者凭据的执行入口：

1. 只接受用户请求携带的凭据，禁用 Keychain、服务端 Codex 和其他环境凭据回退。密钥不落盘、不进日志；向用户说明材料与请求凭据经过网页执行服务。
2. Candidate/Job 执行、取消、幂等缓存按用户会话隔离，不能继续使用全局 operation ID 缓存作为多用户边界。工作区和确认结果仍由浏览器持有，不把本机 `/api/workspace` 开到公网。
3. 限定已验证 Provider/模型/官方端点；有界请求体、文档转图、并发与超时。自带一个兼容 API 地址不自动获得图文/PDF/领域资格。
4. 在真实 HTTPS origin 验收自带 API 的正常、认证失败、缺失凭据、并发隔离、图片/完整 PDF、人工保存路径；同时验收 Codex 的本地网络权限及撤销。部署前不使用真人材料作为默认测试数据。

下载版接下来优先处理工作区位置与恢复指引、全新电脑安装、Gatekeeper、公网下载校验和升级。当前独立包面向 Apple 芯片 Mac；Windows / Intel Mac 仍未验收。现有源码、原件、旧版本和 QA 保留。

## 更方便的 Codex 接法

短期沿用已验证的本地 CLI，减少配对与入口摩擦。官方 [Codex SDK](https://learn.chatgpt.com/docs/codex-sdk) / [App Server](https://learn.chatgpt.com/docs/app-server) 可作为后续登录、真实运行事件及取消的评估路线。需要固定运行时版本，并重新验证单次材料范围、图文/PDF、失败与六个领域契约；本轮没有替换执行协议或承诺更低模型成本。

API 与 Codex 使用不同的认证和计费关系，见 [官方认证说明](https://learn.chatgpt.com/docs/auth)。选择开发审阅模型 Astra 不会自动改变应用内已验证的 Sol 或 DeepSeek 配置。
