正在检查可下载版本…

  1. 解压下载文件，双击「启动 Ariadne.command」。首次自动安装，随后打开浏览器启动页。
  2. 在网页选择运行方式。使用 API 时无需登录 Codex；各模型以实际能力验证结果为准。
  3. 使用 Codex 订阅时，首次双击「登录 Codex.command」完成 ChatGPT 登录，再回网页选择 Codex。
  4. 以后双击启动即可。保持服务终端打开，按 Ctrl+C 停止；资料会保留。

这是未公证的本地测试包。macOS 可能要求在「隐私与安全性」中确认打开；请核对来源与校验值。当前不提供 Windows 或 Intel Mac 版本。

安装包不含你的资料和密钥，也不自动迁移旧开发版资料。端口已被其他版本使用时会提示先停止原服务。首次安装与更新均保留原文件。

仅在使用公开网页版时，才需要「连接网页版.command」和配对码。本地运行无需配对。
