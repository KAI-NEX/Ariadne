材料、额度与权限

模型分析由本机 Codex 发送至 OpenAI，使用登录账号的额度。图片和 PDF 会按原图或完整逐页图片传送；发送材料仍需确认，结果仍由你保存。

如浏览器询问本地网络访问权限，请允许此站点连接本机。连接器需要保持运行；配对最长八小时，停止连接器即可撤销。

断开网页配对

  1. 返回运行方式菜单，打开「连接本地 Codex」。
  2. 点击弹窗底部的「断开本页连接」。本页保存的配对信息会清除；连接器在线时，也会撤销此配对授权，共用该授权的其他页面需重新配对。
  3. 如果连接器离线，页面仍会清除本页配对信息。要确保其他页面也无法继续连接，请停止本机连接器。

停止连接器，撤销所有网页访问

找到运行 python3 scripts/run_codex_connector.py 的终端窗口，按 Ctrl + C。连接器退出后，所有配对授权立即失效；仅关闭这个说明窗或配对窗不会断开已建立的连接。

再次连接时，重新运行该命令，并用新显示的配对码配对。旧配对码与旧授权不能继续使用。

这台电脑直接运行 Ariadne 时

本机直连无需配对连接器；没有网页配对信息时，不会显示「断开本页连接」。要停止后续使用 Codex，请返回运行方式页，选择「本地运行」（不调用模型）或其他已接入模型。断开网页配对本身不会自动更换当前模型；本机直连仍可能使用已选的 Codex。

断开之后会发生什么

已有资料、原件和保存结果会保留，本机 Codex 账号不会退出。已经发送到 OpenAI 的请求不保证能立即停止，可能仍产生额度消耗；网页断连后会明确报错，不会自动切换其他模型。
